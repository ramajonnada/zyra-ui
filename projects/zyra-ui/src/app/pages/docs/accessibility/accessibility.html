Verify it yourself

Don't take our word for it. Every component's live playground on the components page can be tabbed through with a keyboard, and inspected with your browser's accessibility tree or a screen reader (VoiceOver, NVDA). If something doesn't behave the way this page describes, that's a bug — open an issue.

Known limitations

This is a solo-maintained, actively developed library. Accessibility review happens per-component as it ships rather than through a formal third-party audit — so treat this page as "how we build," not a certification. If you rely on ZyraUI in a context with strict compliance requirements (e.g. WCAG conformance reporting), test the specific components you use against your own requirements before shipping.
