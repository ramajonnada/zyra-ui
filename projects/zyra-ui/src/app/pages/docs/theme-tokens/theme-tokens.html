Theme tokens

Every color, radius, font, and transition in Zyra UI is a CSS custom property, organized in three tiers: primitives, semantic tokens, and per-component tokens. Override the semantic layer and everything downstream — including per-component tokens — follows automatically. Prefer to see them applied live? Open the theming page →

What can I change?

Semantic and dimension tokens are the supported customization surface — override these and everything downstream follows. Primitives and per-component tokens are implementation detail: they already derive from the semantic layer, and their names can change between component updates.
