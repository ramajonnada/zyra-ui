Conventions

What every component in the library has in common.

Standalone by default

No NgModules required. Import only the components you use directly into your component's imports array.

Signals-first API

Inputs, outputs, and internal state use input(), output(), and computed() — no @Input/@Output decorators.

zyra-* selectors

Every element and attribute selector is prefixed zyra-, e.g. zyra-button, zyra-data-table.

Token-driven styling

Components read colors, radii, and motion from --zyra-* custom properties — see Theme tokens.
